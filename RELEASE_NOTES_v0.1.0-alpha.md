# EYGGDRANEX v0.1.0-alpha — GENESIS

**Japanese:** エグドラネクス  
**Short form:** EYGGNX

GENESIS is the first public-alpha baseline for the EYGGDRANEX open-ended artificial digital life ecosystem.

## Included

- deterministic 2D digital-life sandbox
- inheritable genome parameters
- metabolism, perception, resource seeking, movement
- reproduction and mutation
- aging, starvation, death and selection
- repeatable seed-based experiments
- initial architecture/specification/research documentation
- brand/licensing boundaries and preliminary naming clearance

## Technical entry point

```bash
python -m pip install -e .
eyggnx --steps 200 --seed 42
```

`eyggdranex` is also provided as a full-name CLI alias in this alpha.

## Alpha note

This release is a research baseline, not a claim that open-ended evolution has already been achieved. Its purpose is to provide a reproducible substrate on which emergence can be measured rather than scripted.
