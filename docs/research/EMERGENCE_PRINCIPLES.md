# Emergence Principles

創発と呼ぶためには、単にランダムな挙動が起きただけでは不十分とする。

## Minimum evidence

1. 行動/形質が直接スクリプトされていない。
2. 同一設定の複数Seedで傾向を比較できる。
3. 対照実験で環境圧または遺伝要素との関連が見える。
4. 実験設定・Seed・バージョンを保存する。
5. 観測者の印象だけでなく定量指標を記録する。

## Example metrics

- population size
- births / deaths
- generation depth
- mean and variance of genes
- resource density
- extinction time
- lineage survival
