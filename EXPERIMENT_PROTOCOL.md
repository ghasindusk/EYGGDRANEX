# Experiment Protocol

全ての重要実験は以下を記録する。

- Experiment ID
- EYGGDRANEX version / commit
- date/time
- random seed
- configuration
- initial population
- initial resources
- duration / ticks
- observed metrics
- unexpected phenomena
- control condition
- interpretation
- reproduction steps

「面白かった」だけで終わらず、第三者が同じ条件を再現できることを優先する。
