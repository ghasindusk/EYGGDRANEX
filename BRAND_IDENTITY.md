# EYGGDRANEX Brand Identity

**Status:** v0.1 public-alpha branding baseline  
**Date:** 2026-09-25

## Canonical naming

- **Official name:** EYGGDRANEX
- **Official Japanese reading:** エグドラネクス
- **Official short form:** EYGGNX
- **Release family:** `EYGGDRANEX v0.1.0-alpha — GENESIS`
- **Technical namespace:** `eyggnx`

## Usage rules

Use **EYGGDRANEX** for repository titles, releases, citations, documentation titles, and public project references.

Use **EYGGNX** for compact technical identifiers such as the CLI, package namespace, experiment IDs, internal modules, and space-constrained UI. Do not shorten the project to `YGGDRA`, `YGG`, `EGGDRA`, or `エグドラ` as official standalone brands.

## Pronunciation

Japanese: **エグドラネクス**.

The spelling and reading are project-defined because EYGGDRANEX is a coined name.

## Public naming principle

The public project should be presented as an original A-Life / digital-life research and software project. Avoid public copy that presents the name as a derivative of, continuation of, or official adaptation of any existing game, animation, manga, mythology-based brand, or software product.

## Logo direction

Preferred motifs: branching evolution, network topology, emergence, seed-to-ecosystem growth, recursive structures, information flow.

Avoid copying or closely imitating existing world-tree logos, recognizable franchise symbols, character silhouettes, or third-party visual identities.
