# EYGGDRANEX Mobile

Android 端末でオフライン実行できる EYGGDRANEX のモバイル実験アプリです。`mobile` は Flutter プロジェクトです。Python 版のコード・過去のタグは変更しません。

## 機能

- **世界**: 個体（緑の丸）・再生する餌（青い丸）・ファイルの餌（琥珀色のひし形、大きさは残量）・デトリタス（紫の三角）を形と色で区別して表示します。凡例のチップで種類ごとに表示を切り替え、「系統で色分け」で創始個体ごとの子孫を色で見分けられます。「世界にあるもの」に、それぞれの数・残量・次の一斉復活までの tick を表示します。開始・一時停止・リセット、3段階の速度。
- **バックグラウンド実行**: 開始後は Android の前景サービスと実行中通知を使い、ホーム画面や画面ロック中もシミュレーションを進めます。アプリに戻ると進んだ状態を表示します。一時停止・リセット・絶滅時にはサービスを停止します。Android 13 以降では初回起動時に通知の許可を尋ねます。許可しなくても実行できますが、通知欄には表示されません。
- **ルール**: バニラから開始。シード、創始個体数、餌の数・再生速度、代謝・移動コスト、突然変異、デトリタス、フォルダから取り込む餌とその一斉復活周期を変更。変更は次のリセットで適用。
- **結果**: 個体数と最大世代の推移（長い実行でも開始時からの全体を保持）。遺伝子ごとに、創始個体の平均からの変化（倍率と上下）、平均の推移、今いる個体の範囲、変異の大きさを表示します。突然変異（変異した誕生の数、大きな変異の数、最近の大きな変異の一覧）、生き残っている系統と上位5系統の割合、餌の種類ごとに食べた量。条件と結果の JSON 共有。
- **フォルダの餌**: Android の標準フォルダ選択画面で指定したフォルダとサブフォルダから最大20件、各ファイルの先頭1 MBを読み込みます。バイト列を zlib 圧縮後サイズから餌のエネルギーに変換し、ゆっくり放出します。ファイルは実行しません。読み込みには Android の文書プロバイダを使い、端末全体へのストレージ権限は要求しません。フォルダの内容を変更した場合は再選択してください。

## 広告

世界・ルールのタブの下に AdMob のバナー広告を表示します（結果のタブには表示しません）。必要な地域では Google の同意画面で選択してから広告を読み込み、結果のタブの「広告のプライバシー設定」で変更できます。デバッグビルドは常に Google のテスト広告です。Release ビルドは `android/admob.properties`（`appId`・`bannerId`、コミットしない）があればその ID を使い、なければテスト広告です。

公開の準備とセキュリティ確認は [PLAY_RELEASE.md](PLAY_RELEASE.md)、プライバシーポリシーの下書きは [PRIVACY_POLICY.md](PRIVACY_POLICY.md) にあります。公開は SHAR-K の承認後に行います。Release ビルドは `android/key.properties`（コミットしない）があればアップロード鍵で署名し、なければデバッグ鍵で署名します（個人の試用のみ）。

## シンボル

琥珀色の種を三つ葉と根が包むマークです。種は生命の始点、枝分かれは進化、根は餌となるデータと生態系の循環を表します。アプリの起動アイコンと画面内に共通して使用します。原画は `assets/brand/eyggdranex-mark.png` です。Android 8 以降の起動アイコンはアダプティブアイコン（`res/mipmap-anydpi-v26`）で、Android 13 以降のテーマアイコン用のモノクロ版も持ちます。ストア用の画像は `store/` にあります。

## Android で実行

```sh
cd mobile
flutter pub get
flutter run
```

APK は `flutter build apk --debug` または `flutter build apk --release` で作ります。成果物は `mobile/build/app/outputs/flutter-apk/` に出ます。Release は現状 Flutter の初期設定に従いデバッグ鍵で署名されるため、個人端末での試用向けです。配布する場合は専用の署名鍵を設定してください。

Windows の Codex アプリ内で Gradle の `Unable to establish loopback connection` が発生する環境向けに、`.github/workflows/mobile-apk.yml` は Linux で解析・テスト・APK ビルドを行い、成果物 `eyggdranex-mobile-apk` を Actions の Artifacts に保存します。APK はアーティファクトの ZIP を展開すると得られます。

バックグラウンド実行はユーザーが開始した実験が対象です。アプリを履歴画面から終了した場合、端末を再起動した場合、Android がプロセスを強制終了した場合は継続しません。画面オフ中も CPU を使うため電池消費が増えます。端末固有の省電力設定によって進行が止まる場合があります。

## Python 版との関係

モバイル版は GENESIS の基本ルール（同じ世界状態を見て移動を決定、餌を公平に分ける、代謝と移動コスト、繁殖、反射境界の変異、デトリタス、データ餌のゆっくり放出と一斉復活）を Dart で実装しています。Python と Dart では乱数生成器や演算順が違うため、同じシードで **Python の simulation contract 2 の軌跡・golden digest と一致しません**。研究結果を比較するときは、同条件を Python 版でも実行してください。

モバイル版には現在、Python 版の空間グリッド最適化、外部データの形式別係数・分割、データ誘導変異と個体学習を移植していません。アプリで選べるルールは画面に表示したものだけです。

JSON 共有にはフォルダ名と相対ファイル名・読み込みサイズが含まれますが、ファイルの中身は含めません。同じデータ餌で再実行するには、元のフォルダを再選択してください。
